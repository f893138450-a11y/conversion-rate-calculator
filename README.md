# 转化率快速计算器

一个适合手机使用的单页静态工具，用于快速计算转化率，并将历史记录保存在浏览器本地。

## 功能

- 输入分子 `detailH0` 与分母 `detailH1`，自动校验格式
- 分母为 `0` 时拦截计算并提示错误
- 结果按百分比展示，保留两位小数
- 历史记录自动保存到浏览器本地存储
- 最多保留 `50` 条历史记录，超出后先进先出覆盖
- 连续重复计算相同数据时，不重复新增历史
- 点击历史记录可回填输入框
- 支持备注、单条删除、清空全部历史

## 文件结构

- `index.html`：页面结构
- `styles.css`：页面样式
- `app.js`：交互逻辑与本地存储

## 本地打开

直接双击 `index.html`，或者在浏览器中打开它即可使用。

## 发布到 GitHub Pages

这个项目已经整理为纯静态站点，适合直接部署到 GitHub Pages。

### 方式一：使用仓库根目录发布

1. 新建一个 GitHub 仓库
2. 把当前目录下所有文件上传到仓库根目录
3. 进入 GitHub 仓库的 `Settings`
4. 打开 `Pages`
5. 在 `Build and deployment` 中选择：
   - `Source`: `GitHub Actions`
6. 推送代码后，GitHub 会自动执行仓库内的 Pages 工作流并发布站点

### 方式二：手动发布静态文件

如果你不想用工作流，也可以：

1. 上传本目录文件到 GitHub 仓库
2. 在 `Settings` -> `Pages`
3. 选择从分支发布
4. 选择 `main` 分支和 `/root`

因为这个项目没有构建步骤，所以两种方式都可以。

## 发布后注意事项

- 历史记录使用浏览器本地存储保存，不会跨设备同步
- 用户清理浏览器缓存、切换浏览器或更换设备后，历史记录不会保留
- GitHub Pages 是静态托管，不影响当前功能使用

## 适合分享的方式

发布成功后，你会拿到一个类似下面的网址：

`https://你的用户名.github.io/你的仓库名/`

把这个链接发给别人即可直接使用。
